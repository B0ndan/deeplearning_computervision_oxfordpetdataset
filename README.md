# AOL Project — Deep Learning and Its Applications

## Project Title

Analisis Perbandingan Arsitektur ResNet50 dan Swin Transformer-Tiny untuk Klasifikasi Fine-Grained 37 Ras Kucing dan Anjing

## Submitted Files

1. `01_dataset_eda.ipynb`
   Dataset preparation, exploratory data analysis, and
   train-validation-test splitting.

2. `02_training_models.ipynb`
   Fine-tuning of ResNet50 and Swin Transformer-Tiny.

3. `03_evaluation_comparison.ipynb`
   Test-set evaluation and model comparison.

## Dataset

Oxford-IIIT Pet Dataset:
https://www.robots.ox.ac.uk/~vgg/data/pets/

The dataset is not included in this submission because of
its file size. The notebooks contain the required directory
configuration and data preparation procedures.
